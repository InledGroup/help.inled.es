# Inled Docs

Welcome to the **Inled Group** documentation. Here you will find guides, tutorials and technical reference for all our projects, organized as **project → subproject → item → document**.

> Dream, Build. Free, private software made with love in Spain.

## How this documentation is organized

- **Projects**: every Inled project has its own section (e.g. *Pulsar OS*).
- **Subprojects**: within a project, components or flavors (e.g. the Pulsar OS editions).
- **Items**: each subproject or project groups concrete items (installation, configuration, API…).
- **Documents**: each item contains documents written in **Markdown**.

Use the sidebar to navigate, or the search box to find any document.

## Get started

1. Pick a project in the left sidebar.
2. Browse its subprojects and items.
3. Read or search for the document you need.

## About Inled

Inled Group is a software brand pioneering development with AI agents and free technologies. Everything we build is **open source**, **auditable** and respects your **privacy**.
